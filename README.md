## 🚀 **v8.2.0 - 最新版（2025年10月10日）**

### 🆕 **受信通知処理の完全リニューアル（v8.2.0）**

#### 🎯 **実装内容**

**1. テキスト抽出による受信通知判定（AND条件）**
- ✅ **償却資産申告書**: 「申告受付完了通知」**かつ**「送信された申告データを受付けました」
- ✅ **給与支払報告書**: 同様のテキスト抽出判定を実装
- ✅ ファイル名に依存しない高精度判定

**2. 2段階マッチングシステム**
- ✅ **Step 1**: 会社名で候補を絞り込み
- ✅ **Step 2**: 候補が1つなら即マッチ
- ✅ **Step 3**: 候補が複数なら市区町村名/税務署名で絞り込み

**3. スペース完全除去**
- ✅ フォルダ名・ファイル名から全角・半角スペースを完全除去
- ✅ 会社名・税務署名から改行・空白を完全除去
- ✅ クリーンで統一された命名規則

#### 📊 **処理フロー詳細**

**償却資産申告書:**
```
1. 本表ファイル処理
   - テキスト抽出で受信通知判定 → スキップ
   - 本表ファイルのみ処理 → フォルダ作成
   - スペース除去: "2505_市原市役所_固定資産税（償却資産）全資産申告（電算処理分）_Ndiot株式会社"

2. 受信通知検出（テキスト抽出）
   - "01_受信通知.pdf" を検出
   - AND条件判定: 「申告受付完了通知」+ 「送信された申告データを受付けました」

3. 受信通知分割・抽出
   - 各ページから会社名と税務署名を抽出
   - 改行・空白を完全除去

4. 2段階マッチング
   - 会社名「株式会社SeasideLink」で候補絞り込み
   - 同一会社が複数 → 税務署名「東京都渋谷都税事務所」で絞り込み
   - マッチしたフォルダに受信通知を配置
```

**給与支払報告書:**
```
1. 本表ファイル処理（償却資産と同様）

2. 受信通知検出（テキスト抽出）

3. 2段階マッチング
   - 会社名で候補絞り込み
   - 同一会社が複数 → 市区町村名で絞り込み
   - マッチしたフォルダに受信通知を配置
```

#### 🔧 **技術実装**

**新規メソッド:**
- `_is_receipt_pdf()`: テキスト抽出によるAND条件判定
- `_extract_company_and_office_from_receipt()`: 会社名・税務署名抽出（改行・空白除去）
- `_match_depreciable_folder()`: 2段階マッチング（会社名→税務署名）
- `_process_payroll_report()`: 給与支払報告書の2段階マッチング対応

**修正メソッド:**
- `_process_main_files_for_special()`: スペース完全除去、テキスト抽出判定
- `_process_depreciable_assets()`: テキスト抽出判定に統一

#### 📈 **改善結果**

| 項目 | v8.1.1 | v8.2.0 | 改善点 |
|------|--------|--------|--------|
| **受信通知判定** | ファイル名ベース | テキスト抽出AND条件 | 高精度化 |
| **マッチング** | 会社名のみ | 2段階（会社名→市区町村/税務署） | 同一会社対応 |
| **命名規則** | スペース残存 | スペース完全除去 | クリーン化 |
| **会社名抽出** | 正規表現 | 行単位抽出+空白除去 | 精度向上 |

## 🚀 **v8.1.1 - 申請届出処理（2025年10月8日）**

### 🆕 **申請届出処理の完全実装（v8.1.1）**

#### 🎯 **実装内容**
1. **顧問先コード自動除去**: フォルダ名・ファイル名から顧問先コード（例: 0801A0094）を自動削除
2. **受信通知ページ分割処理**: 国税・地方税受信通知を1ページずつ分割してから処理
3. **マルチライン申請名抽出**: 複数行にまたがる申請名の正確な抽出
4. **4段階マッチングシステム**: 完全一致 → 部分一致 → キーワード一致 → 共通キーワード一致
5. **受信通知連番対応**: 重複時に `02_受信通知.pdf`, `02_受信通知_02.pdf` と自動採番
6. **国税・地方税バリエーション対応**: 同一申請の国税版・地方税版を同じフォルダに配置

## 🚀 クイックスタート

### 📦 インストール

```bash
git clone https://github.com/Ezark213/tax-doc-renamer.git
cd tax-doc-renamer
pip install -r requirements.txt
python main.py
```

### ⚡ 使用方法

#### 左側機能（源泉税/給与支払/償却資産処理）

1. **プロセスタイプ選択**: 源泉税/法定調書/申請届出/給与支払報告書/償却資産申告書を選択
2. **YYMM入力**: `2505` と入力
3. **本表接頭辞選択**: `01` または `0001` を選択
4. **受信通知接頭辞選択**: `02` または `9999` を選択
5. **全角英字→半角英字変換**: チェックボックスで有効化（任意）
6. **実行**: `🔄 リネーム実行` ボタンをクリック
7. **フォルダ選択**: 処理対象フォルダを選択

#### 右側機能（AI分類）

1. **YYMM入力**: `2505` と入力
2. **自治体設定**: 都道府県・市町村を入力
3. **ドラッグ&ドロップ**: PDFファイルをドロップ
4. **自動処理**: AI自動分類・リネーム実行
