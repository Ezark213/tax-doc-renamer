## 🚀 **v8.0.1 - 最新版（2025年10月1日）**

### 🔧 **FIX: 本表ファイル名から顧問先番号除去（v8.0.1）**

#### 🎯 **修正内容**

**問題:**
- 本表ファイル名に不要な顧問先番号が含まれていた
- 例: `01_報酬・料金等の所得税徴収高計算書_0345N0033_株式会社ＮｏｒｔｈＷｉｎｇ.pdf`

**解決:**
- ✅ 本表ファイル名から顧問先番号（例: 0345N0033）を除去
- ✅ フォルダ名と同じ命名規則に統一
- ✅ 新しい形式: `01_報酬・料金等の所得税徴収高計算書_株式会社ＮｏｒｔｈＷｉｎｇ.pdf`

#### 📋 **命名規則統一**

**フォルダ名:**
```
YYMM_帳票名_会社名/
例: 2511_報酬・料金等の所得税徴収高計算書_株式会社ＮｏｒｔｈＷｉｎｇ/
```

**本表ファイル名:**
```
接頭辞_帳票名_会社名.pdf
例: 01_報酬・料金等の所得税徴収高計算書_株式会社ＮｏｒｔｈＷｉｎｇ.pdf
```

**受信通知ファイル名:**
```
接頭辞_受信通知.pdf
例: 02_受信通知.pdf または 9999_受信通知.pdf
```

## 🚀 **v7.2.3-AMOUNT-MATCHING - 前バージョン（2025年9月30日）**

### ⚡ **NEW! 複数フォルダ金額マッチング（v7.2.3）**

#### 🎯 **v7.2.2の問題と解決**

**v7.2.2の問題**:
- ❌ 同じ会社の複数フォルダ（給与所得・報酬料金など）に対応不可
- ❌ 会社名マッチングが最初のフォルダのみ選択
- ❌ 複数受信通知が誤ったフォルダに配置される

**v7.2.3の解決**:
- ✅ 複数フォルダ検出 → 金額マッチング自動実行
- ✅ 本表金額と受信通知金額を比較して最適配置
- ✅ 単一フォルダは連番保持で即配置（高速処理）

#### 📊 **処理フロー**

**v7.2.2（旧）**: 会社名で最初のフォルダのみ選択
```
受信通知ページ1 → 株式会社X検出 → 最初のフォルダに配置
受信通知ページ2 → 株式会社X検出 → 最初のフォルダに配置
（2つ目のフォルダに受信通知が配置されない）
```

**v7.2.3（新）**: 金額マッチングで最適フォルダ選択
```
受信通知ページ1 → 株式会社X検出 → 2フォルダ検出 → 金額マッチング実行
  - 給与所得フォルダ: 本表50,000円 vs 受信通知50,000円 → 差額0円
  - 報酬料金フォルダ: 本表30,000円 vs 受信通知50,000円 → 差額20,000円
  → 給与所得フォルダに配置 ✓

受信通知ページ2 → 株式会社X検出 → 2フォルダ検出 → 金額マッチング実行
  - 給与所得フォルダ: 本表50,000円 vs 受信通知30,000円 → 差額20,000円
  - 報酬料金フォルダ: 本表30,000円 vs 受信通知30,000円 → 差額0円
  → 報酬料金フォルダに配置 ✓
```

## 🚀 **v7.1.0-SMART-MATCHING - 前バージョン（2025年9月30日）**

### ⭐ **NEW! 会社名マッチング機能（v7.1.0）**

#### 🎯 **実装された機能**

1. **受信通知からの会社名OCR抽出**
   - 受信通知PDF各ページから会社名を自動抽出
   - OCRエンジンによる高精度テキスト認識
   - "様"、"殿"、"御中"などの敬称に対応

2. **インテリジェント会社名マッチング**
   - フォルダ名と受信通知の会社名を自動照合
   - 法人格の正規化（株式会社 ⇔ (株)）
   - 全角・半角文字の統一
   - 旧字体・異体字の統一（髙→高、﨑→崎 など）
   - 部分一致による柔軟なマッチング

3. **高精度配置アルゴリズム**
   - 類似度スコアによる最適フォルダ選択
   - 閾値0.7以上のマッチングのみ許可
   - マッチング失敗時の詳細ログ出力

#### 📊 **処理フロー改善**

**v7.0.0（旧）**: インデックスベース配置
```
受信通知ページ0 → フォルダ0
受信通知ページ1 → フォルダ1
受信通知ページ2 → フォルダ2
（順序が狂うと誤配置）
```

**v7.1.0（新）**: 会社名マッチングベース配置
```
受信通知ページ0 → 会社名抽出 → 最適フォルダ検索 → 正確な配置
受信通知ページ1 → 会社名抽出 → 最適フォルダ検索 → 正確な配置
受信通知ページ2 → 会社名抽出 → 最適フォルダ検索 → 正確な配置
（順序に依存せず、会社名で確実にマッチング）
```

```bash
git clone https://github.com/Ezark213/tax-doc-renamer.git
cd tax-doc-renamer
pip install -r requirements.txt
```

### ⚡ 使用方法

#### 左側機能（源泉税処理）

1. **YYMM入力**: `2511` と入力
2. **本表接頭辞選択**: `01` または `0001` を選択
3. **受信通知接頭辞選択**: `02` または `9999` を選択
4. **実行**: `🔄 フォルダリネーム実行` ボタンをクリック
5. **フォルダ選択**: 処理対象フォルダを選択

#### 右側機能（AI分類）

1. **YYMM入力**: `2511` と入力
2. **自治体設定**: 都道府県・市町村を入力
3. **ドラッグ&ドロップ**: PDFファイルをドロップ
4. **自動処理**: AI自動分類・リネーム実行
