## 🚀 **v8.1.1 - 最新版（2025年10月8日）**

### 🆕 **申請届出処理の完全実装（v8.1.1）**

#### 🎯 **実装内容**
1. **顧問先コード自動除去**: フォルダ名・ファイル名から顧問先コード（例: 0801A0094）を自動削除
2. **受信通知ページ分割処理**: 国税・地方税受信通知を1ページずつ分割してから処理
3. **マルチライン申請名抽出**: 複数行にまたがる申請名の正確な抽出
4. **4段階マッチングシステム**: 完全一致 → 部分一致 → キーワード一致 → 共通キーワード一致
5. **受信通知連番対応**: 重複時に `02_受信通知.pdf`, `02_受信通知_02.pdf` と自動採番
6. **国税・地方税バリエーション対応**: 同一申請の国税版・地方税版を同じフォルダに配置

#### 📊 **マッチングロジック詳細**

**4段階スコアリングシステム:**
- **完全一致** (スコア: 100): 申請名が完全に一致
- **部分一致** (スコア: 80): 一方が他方を含む
- **キーワード一致** (スコア: 60): 先頭60%が一致
- **共通キーワード一致** (スコア: 40-55): 重要キーワードを共有

**重要キーワードリスト:**
申告期限、延長、法人設立、給与支払、源泉所得、青色申告、納期、特例、承認、開設、届出

**マッチング例:**
- 国税: 「定款の定め等による申告期限の延長の特例の申請」
- 地方税: 「第十三号の二様式 申告書の提出期限の延長の処分等の届出書・承認等の申請書」
→ 共通キーワード「申告期限」「延長」でマッチ（スコア: 50）

#### 📝 **処理フロー**
```
1. 本表PDFから申請名を抽出 → フォルダ作成（顧問先コード除去）
2. 国税受信通知.pdf → 1ページずつ分割 → 申請名抽出 → マッチング → 配置
3. 地方税受信通知.pdf → 1ページずつ分割 → 申請名抽出 → マッチング → 配置
4. 重複時は自動連番（_02, _03...）
```

```

  ├── 01_給与所得・退職所得等の所得税徴収高計算書(一般)_0413K0063_会社A.pdf
```
